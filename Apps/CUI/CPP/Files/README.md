# Files of the CUI-CPP App

Offered by the MAS Service with the App (GET /Apps/CPP/Files/...): `companies/index.json` lists the ready-made companies by a plain name, each a company file (the format of the App's README) copied from `Test/Data/CUI/Companies` (synthetic companies made by `Test/Mpai.Cui.Tests/SyntheticCompanies.cs`). Made by `Test/Tools/SrsLj/make_cui_app_files.py`.
